# Task 3.2: Modelos de Enxame com 1 Clique (Swarm Presets) & Injeção de Contexto (Módulo 4) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Desenvolver o catálogo de modelos de enxame pré-configurados (*Swarm Presets*) alinhados com os Trios de Ataque Oficiais (Full-Stack Feature, UI/UX & Desktop, Hotfix & Estabilidade, Arquitetura & Performance, Solo Cockpit), com injeção automática de variáveis de ambiente (`HELM_SWARM_ID`, `HELM_AGENT_ROLE`, `HELM_AGENT_ID`), contexto de persona `.md` do Módulo 4 e lançamento em 1 clique coordenado sobre a grelha de terminais `TiledTerminalGrid`.

**Architecture:**
- `src/config/swarmPresets.ts`: Definição dos tipos `SwarmPreset`, `PresetPanelConfig` e catálogo dos 5 presets oficiais com metadados, layout associado (`1x1`, `1x2`, `2x2`, `2x3`), cores semânticas Apple HIG e variáveis de ambiente.
- `src/stores/useSwarmStore.ts`: Store reativo com `useSyncExternalStore` ou Zustand para gerir presets disponíveis, preset ativo e estado de lançamento (`isLaunching`, `activePresetId`).
- `src/services/swarmLauncher.ts`: Orquestrador de arranque que coordena `agentRegistry`, `gridLayoutStore`, `portService` e `terminalService` para inicializar a grelha e PTYs em menos de 800ms.
- `src/components/swarm/SwarmPresetSelector.tsx`: Componente de catálogo visual Apple HIG com cards táteis (mínimo 44x44px), badges semânticos de papel, preview de layout e lançamento com 1 clique.
- `src/components/swarm/index.ts`: Barrel export.
- `src/App.tsx`: Integração do botão de seleção de enxame na barra superior e montagem do `TiledTerminalGrid` e `SwarmPresetSelector` na área de trabalho ativa.
- `scripts/verify-task-3.2.sh`: Script de validação com typecheck, build e verificação de integridade.
- `scripts/commit-task-3.2.sh`: Script de fecho atómico via Conventional Commits 1.0.0 e fecho do Issue #45.

**Tech Stack:** TypeScript · React 19 · Tailwind CSS v4 · Apple HIG · Tauri 2.x IPC

**Spec:** `docs/ROADMAP.md` § Task 3.2 · GitHub Issue #45
