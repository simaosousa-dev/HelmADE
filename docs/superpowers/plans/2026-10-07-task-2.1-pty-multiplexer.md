# Task 2.1: Motor PTY Multiplexer em Rust com Buffer Circular (Módulo 3) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementar em Rust com a crate `portable-pty` o motor multiplexador de terminais locais (suporte a zsh/bash, até 16 sessões concorrentes), canais bidirecionais de I/O assíncrono (escrita stdin, leitura stdout com emissão de eventos Tauri), ring-buffer de scrollback circular em memória (100.000 linhas) por sessão, comandos IPC Tauri e cliente TypeScript correspondente.

**Architecture:**
- Backend:
  - `src-tauri/src/terminal/ring_buffer.rs`: Estrutura thread-safe `RingBuffer` baseada em `VecDeque<String>` com limite configurável (padrão 100.000 linhas), permitindo inserção rápida em lote, truncamento automático no topo e recuperação de histórico completo.
  - `src-tauri/src/terminal/pty.rs`: Estrutura `PtySession` encapsulando `Child`, `MasterPty`, `Box<dyn Write + Send>`, thread de leitura em background com canal de cancelamento e emissão de eventos Tauri `pty-output-<session_id>`.
  - `src-tauri/src/terminal/manager.rs`: Gestor global `PtyManager` gerindo mapa thread-safe `HashMap<String, PtySession>` com métodos `spawn`, `write`, `resize`, `get_scrollback`, e `kill`.
  - `src-tauri/src/commands/terminal.rs`: Handlers IPC invocáveis a partir do frontend (`spawn_pty`, `write_pty`, `resize_pty`, `kill_pty`, `get_pty_scrollback`).
- Frontend:
  - `src/types/terminal.ts`: Interfaces TypeScript para sessões PTY, dimensões, opções de spawn e eventos de stream.
  - `src/services/terminalService.ts`: Serviço cliente chamando `invoke` e escutando eventos Tauri `listen('pty-output-<id>')`.
- Verificação:
  - `scripts/verify-task-2.1.sh`: Script automatizado com `cargo check`, testes unitários do ring-buffer e teste de integração com 16 PTYs concorrentes.

**Tech Stack:** Rust (`portable-pty = "0.8"`, `serde`, `tauri 2.x`) · TypeScript · Tauri Event System · Apple Silicon / macOS Unix Shells (`/bin/zsh`, `/bin/bash`)

**Spec:** `docs/ROADMAP.md` § Task 2.1 · ADR 0001 · ADR 0005 · GitHub Issue #21

## Global Constraints
- Proibição absoluta de `git stash` e `git stash pop`.
- Custo Absoluto ZERO (0.00€): Nenhuma dependência externa paga ou cloud.
- Thread-safety estrito: nenhum deadlock no I/O do terminal; threads de leitura operam em background sem travar a thread de comando do Tauri.
- Limite de memória determinístico: o ring buffer não deve exceder a capacidade estipulada (100.000 linhas por sessão), garantindo libertação imediata de linhas antigas (FIFO).
- Encerramento limpo: a finalização de uma sessão (`kill`) deve terminar o processo shell filho e liberar os descritores de ficheiro e threads de leitura associados.
- Commits atómicos em formato Conventional Commits 1.0.0 (`feat(pty): ...`).

## Review Focus
1. **Concurrency and Deadlock Freedom**: Execução de 16 PTYs concorrentes sem contenção de mutex ou bloqueio de canal.
2. **High Output Throughput**: Processamento de rajadas de texto ANSI e logs densos sem perda de caracteres nem travamento da interface.
3. **Ring Buffer Bounds**: Verificação de que ao atingir 100.000 linhas, as mais antigas são descartadas sem fugas de memória.
4. **Clean Process Termination**: Eliminação de processos zumbi ou threads órfãs ao fechar um painel.
5. **Window Resizing Integrity**: Sinais de `resize` (cols, rows) aplicados com sucesso à pseudo-terminal virtual no sistema operativo.
