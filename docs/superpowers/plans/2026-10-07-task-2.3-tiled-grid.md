# Task 2.3: Layouts de Grelha Tiled (1x1 a 4x4) e Zoom/Maximizar em 1 Toque (Módulo 3) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Desenvolver o motor de layout em CSS Grid responsivo com alternância dinâmica de 1 a 16 painéis (`1x1`, `1x2`, `2x2`, `2x3`, `3x3`, `4x4`), suporte a zoom/maximização instantânea de painel (`Cmd+Enter` ou duplo clique no cabeçalho), preservação do estado de foco e retenção das sessões PTY sem desmontagem ou reinicialização durante transições de layout.

**Architecture:**
- `src/stores/useGridLayoutStore.ts`: Store leve Zustand gerenciando o layout ativo (`1x1`, `1x2`, `2x2`, `2x3`, `3x3`, `4x4`), lista de painéis (`GridPanel`), painel focado (`activePanelId`), painel maximizado (`maximizedPanelId`) e ações de alternância rápida.
- `src/components/grid/GridLayoutControls.tsx`: Barra de ferramentas com botões de alternância de grelha Apple HIG, atalhos de layout e indicador visual do arranjo de grelha atual.
- `src/components/grid/TiledTerminalGrid.tsx`: Contentor CSS Grid de alto desempenho que renderiza os terminais instanciados via `XTermWrapper`, preservando instâncias DOM vivas mesmo quando ocultas ou redimensionadas, suportando maximização fluida sem destruição de buffers.
- `src/components/grid/index.ts`: Ponto de exportação limpo do módulo de grelha.
- `scripts/verify-task-2.3.sh`: Script de validação automatizada de compilação, tipos e integridade estrutural.

**Tech Stack:** React 19 · TypeScript · Tailwind CSS v4 · Zustand · Apple HIG Design Tokens

**Spec:** `docs/ROADMAP.md` § Task 2.3 · Issue #23 / #12

## Global Constraints
- Proibição absoluta de `git stash` e `git stash pop`.
- Conformidade estrita com Apple HIG: touch/click targets de pelo menos 44x44px nos controlos de layout, contraste WCAG 2.1 AA (>= 4.5:1), materiais semânticos nativos.
- Zero perda de processo: alternar layouts NÃO pode desmontar os terminais nem destruir os processos PTY em execução.
- Atalho nativo: `Cmd+Enter` (macOS) ou `Ctrl+Enter` para maximizar/restaurar o painel focado.
- Commits atómicos seguindo Conventional Commits 1.0.0.

## Review Focus
1. **DOM Preservation**: A troca de grelha (ex.: de `2x2` para `1x1` ou maximização) não deve destruir componentes `XTermWrapper` existentes na árvore.
2. **Apple HIG Controls**: Botões de layout compactos com micro-interações táteis e indicação clara de estado ativo.
3. **Responsive Resize Trigger**: Ao alterar a grelha ou maximizar, disparar redimensionamento automático de colunas e linhas (`FitAddon`).
4. **Clean Keyboard Navigation**: Alternância de foco entre painéis via teclado (`Cmd+Option+Seta` ou `Option+Tab`).
