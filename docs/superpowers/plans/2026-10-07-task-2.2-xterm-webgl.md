# Task 2.2: Integração do @xterm/xterm com WebGL e Renderização Rápida (Módulo 3) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrar no ecossistema React 19 do HelmADE o componente de emulação de terminal baseado em `@xterm/xterm` e `@xterm/addon-webgl`, suportando ANSI TrueColor de 24 bits, auto-dimensionamento responsivo com `FitAddon` e `ResizeObserver`, streaming reativo bidirecional com o motor PTY Rust e temas semânticos Apple HIG.

**Architecture:**
- `src/types/xterm.d.ts`: Declarações de tipos de ambiente para `@xterm/xterm`, `@xterm/addon-fit` e `@xterm/addon-webgl` garantindo conformidade estrita de tipagem e compilação limpa em qualquer ambiente.
- `src/components/terminal/terminalThemes.ts`: Paletas de cores semânticas Apple HIG para terminal (Dark Mode padrão e Light Mode), contraste WCAG 2.1 AA (>=4.5:1), mapeamento ANSI de 16/256 cores e fonte SF Mono.
- `src/components/terminal/useTerminalSession.ts`: Hook reativo React 19 que instancia o terminal `@xterm/xterm`, acopla o `FitAddon` e `WebglAddon` (com fallback elegante para renderizador DOM/canvas), escuta eventos de saída do PTY (`terminalService.onData`) e transmite dados de entrada do teclado para o backend (`terminalService.writePty`).
- `src/components/terminal/XTermWrapper.tsx`: Componente de renderização com moldura Apple HIG, manipulação de redimensionamento via `ResizeObserver`, foco automático e suporte a reconexão.
- `src/components/terminal/index.ts`: Ponto de exportação limpo do módulo de terminal.

**Tech Stack:** React 19 · TypeScript · Tailwind CSS v4 · `@xterm/xterm` · `@xterm/addon-fit` · `@xterm/addon-webgl` · Apple HIG Design Tokens

**Spec:** `docs/ROADMAP.md` § Task 2.2 · GitHub Issue #22 / #11

## Global Constraints
- Proibição absoluta de `git stash` e `git stash pop`.
- Conformidade estrita com Apple HIG: tipografia monospace nativa (`SF Mono`, Menlo, Monaco, monospace), contraste de cores WCAG AA (>= 4.5:1) em todas as cores ANSI.
- Performance de renderização: renderização acelerada por GPU via WebGL addon a 60fps com fallback resiliente para canvas se WebGL não for suportado pelo ambiente da WebView.
- Prevenção de vazamento de listeners: o hook deve desinscrever limpos todos os listeners IPC do Tauri (`UnlistenFn`) e descartar o terminal (`terminal.dispose()`) na desmontagem do componente.
- Commits atómicos seguindo a convenção Conventional Commits 1.0.0.

## Review Focus
1. **Fluid Auto-Resize**: Redimensionamento do contentor do terminal recalcula colunas e linhas (`fitAddon.fit()`) e envia o novo tamanho para o PTY via `terminalService.resizePty`.
2. **WebGL Fallback Resilience**: Se a criação do contexto WebGL falhar na WebView, a aplicação não deve crashar, caindo suavemente para o renderizador padrão.
3. **TrueColor ANSI Support**: Suporte completo a sequências ANSI de 24 bits e estilos de texto (negrito, itálico, sublinhado, cores de fundo).
4. **Scrollback Hydration**: Ao montar o componente, o histórico retido no `RingBuffer` de Rust é descarregado instantaneamente no terminal sem perda de ordem.
5. **Clean Unmount & Memory Management**: Desmontar o componente remove listeners de dados, desvincula o `ResizeObserver` e executa `dispose()` nos addons e no terminal.
