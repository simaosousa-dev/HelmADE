# Task 3.1: Descoberta e Leitura de Personas .md no Sistema (Módulo 4) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Desenvolver o motor em Rust e serviço TypeScript para descobrir, ler e analisar todos os ficheiros de persona de agentes em formato Markdown (`.md` / `AGENT.md`), indexando tanto os agentes globais do sistema (`~/.gemini/config/agents/` ou `~/.helm/agents/`) como os agentes locais do projeto ativo (`.helm/agents/`), extraindo metadados YAML frontmatter (`name`, `description`, `role`, `tools`, `skills`, `system_prompt`) e expondo comandos IPC do Tauri para o frontend.

**Architecture:**
- `src-tauri/src/agents/mod.rs`: Módulo agregador de agentes em Rust.
- `src-tauri/src/agents/parser.rs`: Parser robusto de YAML frontmatter em Markdown (extrai `name`, `description`, `tools`, `skills`, flags, e o corpo markdown como prompt de sistema), com tratamento gracioso de falhas sintáticas.
- `src-tauri/src/agents/scanner.rs`: Motor de descoberta que varre diretórios recursivamente (`~/.gemini/config/agents/`, `~/.helm/agents/`, e `.helm/agents/` no projeto), deduplicando por nome de agente com precedência do projeto.
- `src-tauri/src/commands/agents.rs`: Comandos IPC Tauri:
  - `list_discovered_agents(project_path: Option<String>) -> Result<Vec<AgentDefinition>, String>`
  - `get_agent_details(agent_id: String, project_path: Option<String>) -> Result<AgentDefinition, String>`
- `src-tauri/src/lib.rs`: Registo do módulo `agents` e inclusão dos comandos `list_discovered_agents` e `get_agent_details` no `generate_handler!`.
- `src/types/agent.ts`: Contratos TypeScript espelhando `AgentDefinition`, `AgentMetadata` e fontes (`global` vs `project`).
- `src/services/agentRegistry.ts`: Serviço frontend para invocar os comandos Tauri e gerir cache local de agentes.
- `scripts/verify-task-3.1.sh`: Script de validação (testes unitários Rust `cargo test agents`, typecheck e build).

**Tech Stack:** Rust · Tauri 2.x · Serde / Serde JSON · TypeScript · React 19

**Spec:** `docs/ROADMAP.md` § Task 3.1 · Issue #44

## Global Constraints
- Proibição absoluta de `git stash` e `git stash pop`.
- Resiliência: se um ficheiro `.md` tiver YAML inválido ou corrupto, o scanner não deve crashar; deve registar o aviso e continuar a carregar os restantes agentes.
- Test-Driven Development: testes unitários em Rust validando parsing de frontmatter válido, ausente e malformado.
- Commit final via `devops-release` com formato Conventional Commits 1.0.0.
